## 一、环境要求与安装

| 项目 | 要求 |
|---|---|
| PHP | 7.4+(推荐8.0-8.2),扩展:pdo_mysql / curl / gd / mbstring / zip / fileinfo |
| 数据库 | MySQL 5.6+ / MariaDB / MySQL 8.0 |
| 部署方式 | 宝塔面板(推荐)/ Docker / Windows(phpstudy/IIS) |

**安装三步**:上传程序到站点根目录 → 浏览器访问 `http://域名/install/` → 按向导填写数据库与管理员账号。

- 安装完成后程序会**自动锁定安装器**并尝试删除 install 目录(Linux);Windows/IIS 用户请手动删除 install 目录
- 伪静态规则见 DEPLOY.md(nginx/Apache/IIS 三种都有)
- Docker 部署:`cp .env.example .env` 修改数据库密码后 `docker compose up -d`

## 二、安装向导详解

1. **环境检测**:全部绿勾才能继续(缺扩展回phpstudy/BT面板启用)
2. **数据库连接**:主机(默认 localhost)、端口3306、数据库名(建议不存在,向导会自动建库)、账号密码
3. **管理员账号**:3-20位字母数字;密码至少8位——**此账号即后台超管,务必牢记**

安装成功后自动生成 `data/config.php`(数据库配置)与 `data/install.lock`(安装锁)。

## 三、首次配置清单(装完必做的8件事)

1. ✅ 登录后台 `/admin.php`,**立即修改管理员密码**(系统设置→修改密码)
2. ✅ 系统设置→**网站名称/SEO关键词/描述/备案号**
3. ✅ 系统设置→**固定站点域名**(强烈推荐:填你的域名如 `example.com`,支付回调与外链固定,不随Host头变化)
4. ✅ 系统设置→**默认模板**(kylite免费; kunpro/iqiyi为付费主题,需授权)
5. ✅ 采集中心→**添加采集接口**(见第四节)
6. ✅ 系统设置→**人机验证**(默认图形验证码开箱即用;有极验/Turnstile账号可切换)
7. ✅ 系统设置→**SMTP邮件配置**(注册/找回密码依赖:填阿里云邮件推送等SMTP信息)
8. ✅ 服务器配置每日定时任务(见第十节:cron采集 + 每日备份)

## 四、采集系统详解(核心功能)

### 4.1 添加采集接口

采集中心 → 接口列表 → **添加接口**:填名称(如"极速资源")与接口地址(资源站提供的 api.json 地址,如 `https://xx.com/api.php/provide/vod/from/dbm3u8/at/json`)。

- 接口列表有**「接口健康」列**:打开页面自动并发检测全部接口——✅ 绿标"正常(耗时,总页数)" / ❌ 红标"接口挂了(HTTP 502,上游资源站故障)",点击标可重测
- 上游资源站忽上忽下是常态,某源挂了等它恢复即可(定时采集会自动补),其余源不受影响

### 4.2 三种采集方式

| 方式 | 入口 | 适用场景 |
|---|---|---|
| **快速采集** | 接口列表→快速采集 | 弹窗选范围(默认仅最近24小时更新)与起始页,逐页采集入库 |
| **进入采集** | 接口列表→进入采集 | 最完整:先预览资源站内容(片名/分类/备注),选分类与范围后采集;实时日志+进度条+统计卡片 |
| **定时采集** | 采集中心顶部按钮 | 手动触发一轮全部启用接口的增量更新(通常配合服务器cron使用) |

- 采集按**条目去重**:已入库的影片只增量并入播放地址,重复采集不会产生重复数据
- **采集速度**:温和(2.6秒/页)~快速(0.35秒/页),对上游友好的服务器建议"标准"或"温和"
- 单页采集在后台异步执行(可达数分钟),页面实时显示"后台采集中(已X秒)",**请勿关闭页面**;超时会自动重试并只补剩余条目
- 病态卡死的采集进程由系统15分钟自动强杀,不会无限占用资源

### 4.3 服务器定时自动采集(推荐)

宝塔面板 → 计划任务 → Shell脚本,每30分钟执行一次:

```bash
/www/server/php/82/bin/php /www/wwwroot/你的站点/ky/cron/collect.php
```

定时采集只拉取"最近更新"的增量,配合每日备份形成自动运营。

### 4.4 封面图片存储

采集中心 → 图片存储:本站(默认,存到 `/upload/vod` 并压缩至宽480px)/ FTP / OSS / S3兼容(B2/COS/MinIO)。切换后点**「测试存储」**验证。云盘模式下填"外链域名",图片直链不占本站带宽。

## 五、内容管理

- **影片列表**:搜索/编辑/上下架/删除(删除会连带清理评论、收藏、播放记录、购买记录);支持批量操作与影片合并(后台自动扫描同名影片)
- **新增影片**:手工录入影片(与采集影片互不冲突)
- **分类管理**:分类支持**主/副分级**——主分类上导航栏,副分类进所属主分类的下拉;修改后自动刷新导航缓存
- **幻灯管理**:预留配置(当前前台轮播直接使用影片数据)
- **评论管理**:待审核/全部评论的清理与删除(可在系统设置开启"评论先审后显")
- **求片管理**:用户提交的影片需求,标记完成后从列表移除,可作为内容采购参考
- **友链/文章**:友情链接(页脚展示)与站内文章(公告/帮助页)

## 六、会员与付费

### 6.1 会员体系

- 会员注册需邮箱验证码(依赖SMTP配置);后台可整体关闭注册/评论
- 会员字段:积分(签到/消费/充值)、VIP到期时间、收藏、播放记录、求片记录

### 6.2 VIP套餐与支付

1. 会员 → **商品管理**:添加套餐(VIP天数或积分、价格、排序)
2. 系统设置 → 支付配置,按需启用:易支付 / 码支付 / USDT-TRC20(免挂,填地址与汇率) / 微信 / 支付宝
3. 用户前台购买:支付成功经**异步回调自动发货**(VIP延长或积分到账);订单按下单时的套餐快照发货,后台改套餐不影响已建订单
- 回调地址使用「固定站点域名」配置,务必先设好
- USDT需服务器能访问 TronGrid API;订单有未支付数量限制防刷

### 6.3 积分

签到、注册、充值比例均可配置;单部影片可设积分购买(VIP标识),用户购买后永久可看。

## 七、主题与外观

- **kylite**(免费,明亮):轻量影视模板
- **kunpro / iqiyi**(付费,暗色):需购买授权,授权后后台市场在线安装,系统设置→默认模板切换
- 切换主题后请 **Ctrl+F5** 强制刷新浏览器缓存
- 广告位:首页顶部/播放页顶部/底部/页脚,后台独立开关+代码,适合挂统计或联盟代码

## 八、系统设置逐项说明

| 设置项 | 说明 |
|---|---|
| 固定站点域名 | 防Host头污染,支付回调/外链固定域名(**必配**) |
| 影视站模式 | CMS板块+翻页 / 瀑布流无限滚动 / 电影海报墙 |
| 人机验证 | 图形验证码(默认)/ 极验v4 / Cloudflare Turnstile |
| 评论 | 开关+先审后显 |
| SMTP | 注册/找回密码邮件(阿里云邮件推送等) |
| 积分 | 签到/注册赠送/充值比例 |
| 搜索限流 | 每IP次数/窗口(防刷) |
| CDN加速 | 经Cloudflare等CDN时开启(影响真实IP获取) |
| HTTP验证 | 请求外部资源校验TLS证书(默认开) |
| 广告位 | 各位置独立开关+代码 |

## 九、SEO与推广

- sitemap: `http://域名/index.php?s=/index/sitemap`;RSS: `?s=/index/rss`
- **百度推送**:系统设置填站点与token后,每次采集到新片自动推送给百度收录
- 伪静态(detail-xx.html)默认开启,利于收录
- robots.txt 在程序根目录,部署后把其中Sitemap行改成你的域名

## 十、运维:备份 / 自检 / 日志 / 更新

### 每日备份(强烈建议配置cron)

```bash
/www/server/php/82/bin/php /www/wwwroot/你的站点/ky/cron/backup.php
```

纯PHP实现免mysqldump,gzip输出到 `data/backup/`,自动轮转保留7份。配置了云存储(FTP/OSS/S3)会**自动上传异地一份**。

### 一键自检

```bash
php ky/cron/selftest.php
```

36项体检:PHP扩展/数据表结构/付费主题密钥/授权令牌/出站HTTP/SSRF防护/目录权限/配置健康。**升级或异常排查先跑它**,可挂cron做日常监控。

### 错误日志

PHP错误落盘 `data/log/php_error.log`(每日维护自动轮转)。站点异常时先看这里。

### 在线更新

后台 → 拓展:检测并在线更新(带sha256完整性校验)。更新前自动备份被覆盖文件到 `data/cache/backup_*`。

## 十一、常见问题FAQ

**Q: 验证码不显示 / 总提示验证码错误?**
GD未启用,或跨请求会话丢失。运行根目录 `diagnose_captcha.php` 逐项自诊断(诊断后删除)。

**Q: 采集提示"接口挂了"?**
上游资源站故障(接口健康列会显示HTTP状态),等它恢复或先采其他源。

**Q: 采集一页要很久?**
每页含20部影片的封面下载与压缩,数分钟属正常;采集在后台异步执行,页面有实时进度。

**Q: 注册/找回密码收不到邮件?**
检查SMTP配置;可用自检脚本验证出站HTTP与SMTP连通性。

**Q: 支付后没到账?**
查会员→订单状态;回调依赖「固定站点域名」配置正确;异常取消的订单收到有效回调会自动补发。

**Q: 升级后想确认一切正常?**
跑 `php ky/cron/selftest.php`,全部PASS即健康。

**Q: 忘记管理员密码?**
数据库重置 ky_admin 表对应用户的 pwd 字段为 `password_hash("新密码", PASSWORD_DEFAULT)` 的值。
